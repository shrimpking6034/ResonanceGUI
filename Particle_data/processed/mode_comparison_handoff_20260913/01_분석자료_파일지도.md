# 모드 차수 비교 분석 자료 파일 지도

모든 경로는 프로젝트 루트 `ResonanceGUI/` 기준 상대경로다. 이 문서는 “어떤 이름의 파일에 무엇이 있는가”를 설명한다.

## 1. 최종 문서와 계산 중간물

| 경로 | 내용 | 중요도 |
| --- | --- | --- |
| `Particle_data/processed/20260913_모드차수_비교분석_20260911_vs_20260910_5thmode_220um.md` | 최종 결론, 공통 조건 표, 기존 결과 재현, guard 민감도, 왕복 비대칭, 한계, 권장 실험을 모두 담은 주 보고서 | 가장 먼저 읽기 |
| `.codex_tmp/compare_modes_20260913.py` | 6개 세션을 읽어 기존 SNR을 검증하고 5개 window/guard 조건, 왕복쌍, 방향별 통계, 압력 전환 겹침, SHA-256을 계산한 일회성 비교 스크립트 | 재현 참고. `.gitignore` 대상 |
| `.codex_tmp/mode_comparison_20260913.json` | 위 스크립트의 전체 구조화 결과. 이벤트별 공통 조건 SNR, 메타데이터, 해시 포함 | 가장 상세한 기계 판독 중간 결과. `.gitignore` 대상 |
| `.codex_tmp/mode_comparison_log.txt` | JSON 중 핵심 통계를 사람이 훑기 쉽게 출력한 실행 로그 | 보조 자료. `.gitignore` 대상 |
| `.codex_tmp/write_mode_report_20260913.py` | 최종 Markdown 보고서를 조립할 때 사용한 일회성 작성 스크립트 | 보고서 생성 이력. 분석 공식의 기준 파일은 아님 |

`.codex_tmp`가 전달되지 않아도 최종 보고서와 원자료, 후보 CSV, 아래의 제품 코드로 핵심 수치를 다시 만들 수 있다. 재현 방법은 [계산 재현 가이드](02_계산_재현가이드.md)에 있다.

## 2. 원시 측정 CSV 6개

분석에 실제 사용한 원시 파일은 아래 6개뿐이다.

| 파일 | 분석상 의미 | 대표 공진 주파수 | 기록 길이 |
| --- | --- | ---: | ---: |
| `Particle_data/raw/raw_20260911_2ndmode_P.csv` | 9/11 2차, P-only PLL | 4,440.90 Hz | 161.65 s |
| `Particle_data/raw/raw_20260911_3rdmode_P.csv` | 9/11 3차, P-only PLL | 8,741.22 Hz | 385.82 s |
| `Particle_data/raw/raw_20260911_4thmode_2.csv` | 9/11 4차 두 번째 기록, 목표 BW 표시 3 Hz | 14,290.05 Hz | 115.38 s |
| `Particle_data/raw/raw_20260911_4thmode_3.csv` | 9/11 4차 세 번째 기록, 목표 BW 표시 80 Hz | 14,290.34 Hz | 117.07 s |
| `Particle_data/raw/raw_20260911_5thmode.csv` | 9/11 5차, 최우선 추천의 근거 세션 | 21,349.38 Hz | 58.66 s |
| `Particle_data/raw/raw_20260910_5thmode_220um.csv` | 날짜 간 비교용 9/10 5차 세션 | 21,340.94 Hz | 128.34 s |

원시 CSV의 맨 위 `# Metadata,...` 행에는 세션 ID, PLL 계수와 목표 BW, 필터 TC/order, 위상 목표, 구동 전압, 유체·입자 표기, 샘플링 정보 등이 있다. 데이터 행에는 적어도 `Time_s`, `Frequency_Hz`, `PressureCommand_A_V`, `PressureCommand_B_V`가 있으며, SNR 재계산은 시간과 주파수를, 압력 전환 오염 확인은 두 pressure command 열을 사용한다.

같은 폴더의 다음 파일들은 이번 6세션 비교에 사용하지 않았다: `raw_20260911_3rdmode_PID.csv`, `raw_20260911_4thmode.csv`, `raw_20260910_4thmode_220um*.csv`, `raw_20260910_202521_0cba5a72.csv`, `sweep_*.csv`. 이름이 비슷하다는 이유로 자동 추가하지 않는다.

## 3. 세션별 후보 폴더

분석한 후보 폴더는 정확히 아래 6개다.

```text
Particle_data/processed/
├── 20260911/
│   ├── particle_graphs_20260911_2ndmode/
│   ├── particle_graphs_20260911_3rdmode/
│   ├── particle_graphs_20260911_4thmode_2/
│   ├── particle_graphs_20260911_4thmode_3/
│   └── particle_graphs_20260911_5thmode/
└── 20260910/
    └── particle_graphs_20260910_5thmode_220um/
```

각 폴더에서 같은 이름이 반복되며 역할은 다음과 같다.

| 파일 패턴 | 들어 있는 내용 | 이번 분석에서의 사용 |
| --- | --- | --- |
| `retained_review.csv` | 저장된 후보 한 행당 시간, 이벤트 시작/끝, 지속시간, 검출 방식, `depth_hz`, 상태, 품질 및 일부 물성/왕복쌍 열 | 후보 시간과 신호 깊이의 기준. 핵심 입력 |
| `retained_review.json` | 원본 `source` 경로, 검출 설정, 원시 메타데이터, 압력 전환 시각, 노이즈 설정, 물성 설정/보정 | 설정과 메타데이터 확인. 핵심 입력 |
| `noise_snr/snr_summary.csv` | 기존 분석의 이벤트별 전/후 σ, pooled σ, SNR, 10σ 통과 여부 | 기존 수치 재현 검증에 사용 |
| `noise_snr/snr_analysis_settings.json` | 기존 SNR의 원본 경로와 `window_s`, `guard_s`, drift 차수, σ 정의 | 날짜별 기존 조건 차이 확인 |
| `noise_snr/snr_report.md` | 기존 SNR 요약을 사람이 읽는 보고서 | 이전 추천 및 기존 평균 확인 |
| `noise_snr/snr_context_noise.csv` | 이벤트 전후 노이즈 구간별 원자료 요약 | 세부 진단용. 최종 표의 직접 입력은 아님 |
| `noise_snr/snr_residuals.csv` | 각 노이즈 구간에서 선형 drift를 뺀 잔차 시계열 | 세부 검증/그래프 재생성용 |
| `noise_snr/snr_context_overview*.png` | 이벤트 주변 파형과 detrended residual 페이지 | guard 오염과 파형을 눈으로 확인 |
| `001_....png`, `002_....png`, ... | 각 저장 후보의 개별 파형 그림. 파일명 숫자는 후보 순번과 중심 시각 | 대표 파형 3개와 후보 형태를 시각 확인 |
| `context_noise.csv` | GUI가 저장한 후보 주변 노이즈 통계 | 기존 GUI 산출물. 공통 조건 재계산의 기준 파일은 아님 |
| `exported_events.csv` | 내보내기용 후보/이벤트 표 | 보조 산출물 |
| `raw_*_review.csv`, `raw_*_review.json` | 저장 당시 전체 검토 결과와 설정 | `retained_review.*`의 원형/백업 성격 |
| `raw_*_review_round_trip_pairs.csv` | 9/11 세션에서 시간순으로 묶은 완전 왕복쌍 요약 | 왕복 평균 재현 대조에 사용 |
| 폴더 안의 `raw_*.csv` | 일부 세션에서 원시 CSV가 후보 폴더에도 복사되어 있음 | 중복본일 수 있음. 공식 입력은 `Particle_data/raw/`의 동명 파일로 통일 |
| `particle_noise_snr_<timestamp>/` | 과거 시점의 별도 SNR 내보내기 스냅샷 | 독립 세션으로 집계하지 않음 |

중요: `retained_review.json`과 `snr_analysis_settings.json`의 `source`에는 이 PC의 절대경로 또는 과거 파일 위치가 남아 있다. 다른 컴퓨터에서는 `Path(source).name`으로 basename만 얻고 `Particle_data/raw/<basename>`에 연결한다.

## 4. 계산 로직을 정의하는 코드

| 파일 | 관련 함수/내용 | 역할 |
| --- | --- | --- |
| `particle_review_core.py` | `load_raw`, `_noise_metrics`, `event_context_noise`, `batch_context_noise`, `pressure_changes` | 메타데이터 포함 원시 CSV 로드, 앞/뒤 구간 추출, 각 구간 drift 제거와 σ 계산 |
| `particle_review_noise.py` | `analyze_noise`, `save_noise_analysis` | pooled σ와 이벤트별 SNR 계산, CSV/JSON/MD/PNG 저장 |
| `analyze_review_snr.py` | CLI 진입점 | 폴더의 후보와 원시 파일을 불러 기존 방식의 SNR 분석 실행. 기본 `window_s=1.0`, guard는 인자로 받음 |
| `particle_review_gui.py` | 후보 검토/저장 GUI | `retained_review.*`가 만들어진 사용자 작업 흐름 이해용 |
| `particle_review_export.py` | 후보 그래프·표 내보내기 | PNG, review CSV/JSON 등 파생 파일 생성 |
| `resonance_gui.py` | 측정 메타데이터 저장 부분, PLL 설정 UI | `PLL_target_bandwidth_Hz`가 목표 입력값임을 확인한 근거 |

주의: 제품 코드의 함수는 현재 워크스페이스 버전을 기준으로 확인했다. 당시 실행 EXE와 소스가 완전히 동일하다는 별도 버전 증명은 없다.
