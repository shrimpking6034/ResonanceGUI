# 모드 차수 비교 계산 재현 가이드

## 1. 재현하려는 기준

주 비교 조건은 다음과 같다.

- 후보: 6개 후보 폴더의 `retained_review.csv` 전 행, 총 80개
- 신호 크기 `D`: `abs(depth_hz)`
- 이벤트 중심: `time_s`
- 앞 노이즈 구간: `[t0 - guard - window, t0 - guard]`
- 뒤 노이즈 구간: `[t0 + guard, t0 + guard + window]`
- `window = 0.5 s`, `guard = 0.25 s`
- 앞/뒤 구간에 각각 별도의 1차 직선을 피팅한 뒤 잔차 표준편차 계산
- 표준편차: 모집단 표준편차 `ddof=0`
- 평활화, 보간, 리샘플링 없음
- `sigma_pooled = sqrt((n_before*sigma_before^2 + n_after*sigma_after^2) / (n_before+n_after))`
- `SNR = D / sigma_pooled`
- `SNR >= 10`이면 이 보고서의 10σ 기준 통과

## 2. 필요한 Python 환경

프로젝트 루트에서 Python 3와 `numpy`, `pandas`가 필요하다. 그림 재생성에는 `matplotlib`도 필요하다. 현재 제품 함수로 계산할 때는 프로젝트 루트가 import 경로에 있어야 한다.

## 3. 경로 이식 규칙

JSON의 `source`는 다른 PC에서 깨질 수 있다. 반드시 아래처럼 basename으로 다시 연결한다.

```python
source = ROOT / "Particle_data" / "raw" / Path(info["source"]).name
```

9/10 후보 폴더 안에도 같은 이름의 원시 CSV가 있으나, 비교에서는 `Particle_data/raw/`의 파일을 기준으로 통일한다.

## 4. 공통 조건을 재계산하는 최소 스크립트

다음 코드를 프로젝트 루트에서 실행하면 세션별 후보 수, 평균 σ, 평균/중앙/최저/최고 SNR, 10σ 통과 수가 출력된다. 파일에는 쓰지 않는다.

```python
from pathlib import Path
import json
import numpy as np
import pandas as pd

from particle_review_core import load_raw, batch_context_noise

ROOT = Path.cwd().resolve()
folders = [
    ROOT / "Particle_data/processed/20260911/particle_graphs_20260911_2ndmode",
    ROOT / "Particle_data/processed/20260911/particle_graphs_20260911_3rdmode",
    ROOT / "Particle_data/processed/20260911/particle_graphs_20260911_4thmode_2",
    ROOT / "Particle_data/processed/20260911/particle_graphs_20260911_4thmode_3",
    ROOT / "Particle_data/processed/20260911/particle_graphs_20260911_5thmode",
    ROOT / "Particle_data/processed/20260910/particle_graphs_20260910_5thmode_220um",
]

for folder in folders:
    info = json.loads((folder / "retained_review.json").read_text(encoding="utf-8-sig"))
    source = ROOT / "Particle_data/raw" / Path(info["source"]).name
    data, _metadata = load_raw(source)
    events = pd.read_csv(folder / "retained_review.csv").sort_values("time_s").reset_index(drop=True)

    contexts = batch_context_noise(
        data,
        events.to_dict("records"),
        window_s=0.5,
        guard_s=0.25,
        detrend_degree=1,
    )
    counts = contexts["sample_count"].to_numpy().reshape(-1, 2)
    side_sigma = contexts["detrended_std_hz"].to_numpy().reshape(-1, 2)
    sigma = np.sqrt((counts * side_sigma**2).sum(axis=1) / counts.sum(axis=1))
    snr = events["depth_hz"].abs().to_numpy() / sigma

    print(
        folder.name,
        {
            "n": len(events),
            "sigma_mean": float(sigma.mean()),
            "snr_mean": float(snr.mean()),
            "snr_median": float(np.median(snr)),
            "snr_min": float(snr.min()),
            "snr_max": float(snr.max()),
            "pass_10sigma": int((snr >= 10).sum()),
        },
    )
```

## 5. 기존 SNR 산출물의 의미

각 폴더의 `noise_snr/`는 공통 조건 결과가 아니라 저장 당시 조건의 결과다.

- 9/11 다섯 세션: `window_s=1.0`, `guard_s=0.1`, 1차 drift 제거
- 9/10 5차: `window_s=0.5`, `guard_s=0.05`, 1차 drift 제거

그래서 기존 `snr_summary.csv`끼리 바로 비교하지 않고, 최종 보고서에서는 모든 세션을 0.5/0.25 조건으로 다시 계산했다. 기존 결과는 구현 재현 검증과 이전 추천 수치 확인에 사용했다.

`analyze_review_snr.py`의 현재 CLI는 window를 1.0초로 고정하므로, 그것만 실행해서 주 비교의 0.5/0.25 결과가 나온다고 기대하면 안 된다. 위 최소 스크립트나 `.codex_tmp/compare_modes_20260913.py`를 사용한다.

## 6. 왕복쌍 통계 재현

최종 보고서는 후보를 `time_s`로 정렬하고 순서상 `(1,2)`, `(3,4)`, ...를 왕복쌍으로 묶었다. 홀수 개면 마지막 이벤트는 쌍 통계에서 제외한다.

```python
depth = events["depth_hz"].abs().to_numpy()
pairs = depth[: (len(depth) // 2) * 2].reshape(-1, 2)
pair_mean = pairs.mean(axis=1)
pair_mean_cv_percent = pair_mean.std(ddof=1) / pair_mean.mean() * 100
mean_round_trip_difference_percent = np.mean(
    np.abs(pairs[:, 0] - pairs[:, 1]) / pair_mean
) * 100
```

이 짝짓기는 9/11의 `raw_*_review_round_trip_pairs.csv`와 수치 대조했지만, 같은 입자의 실제 왕복이라는 독립 증명은 아니다.

## 7. 분석을 확장할 때 지켜야 할 구분

- 새 원시 세션을 추가할 때는 기존 후보 선택 기준이 같은지 먼저 확인한다. 9/10과 9/11의 탐색 폭과 최소 문턱이 이미 다르다.
- 공정한 모드 고유 성능 비교에는 같은 입자, 유동, 장착, 구동, 실제 추종 응답을 통제한 교차 실험이 필요하다.
- `particle_property_settings`의 차수·감도·지름 범위가 맞기 전에는 저장된 질량, 밀도, 등가지름을 차수 비교에 합치지 않는다.
- 평균 SNR 하나만 보지 말고 중앙값, 하위 분포, 방향별 깊이, 왕복쌍 평균 CV, 빈 유체 오검출과 알려진 통과 누락을 함께 본다.
- 새로운 결론을 쓸 때는 “저장 후보 내 품질”과 “전체 검출 효율”을 명시적으로 구분한다.
